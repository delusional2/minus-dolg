# Минус долг: установка на айфон

## 1. Открыть проект
Дважды кликни `MinusDolg.xcodeproj` в этой папке. Откроется Xcode.

## 2. Подписать своим Apple ID (один раз)
1. Xcode → Settings → Accounts → «+» → Apple ID → войди своим Apple ID.
2. Слева кликни на синюю иконку проекта **MinusDolg** → вкладка **Signing & Capabilities**.
3. В поле **Team** выбери себя (Personal Team).
4. Если Xcode ругается на Bundle Identifier, поменяй `com.ilvmr.minusdolg` на любой свой, например `com.ilvmr.minusdolg2`.

## 3. Подключить айфон
1. Подключи айфон к Маку кабелем, на телефоне нажми «Доверять этому компьютеру».
2. На айфоне: Настройки → Конфиденциальность и безопасность → **Режим разработчика** → включить (телефон перезагрузится).
3. В Xcode наверху, где выбирается устройство, выбери свой айфон.

## 4. Установить
Нажми ▶ (Cmd+R). Приложение соберётся и появится на айфоне.

Если при первом запуске айфон пишет «Ненадёжный разработчик»:
Настройки → Основные → VPN и управление устройством → твой Apple ID → Доверять.

**Важно:** с бесплатным Apple ID приложение работает 7 дней. Потом просто снова подключи телефон и нажми ▶ в Xcode, траты при этом сохранятся.

## 5. Автозапись SMS от 900
В приложении во вкладке «Настройки» есть пошаговая инструкция. Коротко:
1. «Команды» → «Автоматизация» → «+» → «Сообщение».
2. Отправитель: 900. Сообщение содержит: `Покупка`. Отметь «Запускать сразу».
3. «Новая пустая автоматизация» → действие **«Записать SMS от 900»** (Минус долг).
4. В поле «Текст SMS» выбери переменную **«Ввод быстрой команды»**.

Теперь каждая покупка записывается сама, и приходит уведомление: сколько потратил и сколько ещё можно сегодня.
Если Сбер присылает и SMS со словом «Оплата», сделай вторую такую же автоматизацию.
