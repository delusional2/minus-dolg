# Минус долг

Трекер трат по SMS от 900: лимиты на еду и такси, сколько можно потратить сегодня, счётчик возврата долга.

## Как пользоваться на айфоне
1. Открой в **Safari**: https://delusional2.github.io/minus-dolg/
2. «Поделиться» → «На экран Домой» → «Добавить».
3. Открывай с иконки. При первом запуске проверь цифры в настройках.
4. Пришла SMS от 900 — скопируй, нажми «+ Добавить траты», вставь.

Данные хранятся только на телефоне (в памяти этого приложения).

## Папка `ios/`
Нативная версия на SwiftUI с автозаписью SMS через «Команды». Собирается в Xcode, см. `ios/КАК УСТАНОВИТЬ.md`.
