# Минус долг

Трекер трат по SMS от 900: лимиты на еду и такси, сколько можно потратить сегодня, счётчик возврата долга. Траты сохраняются в бесплатной базе Supabase, видишь их только ты.

## 1. Поставить на айфон
1. Открой в **Safari**: https://delusional2.github.io/minus-dolg/
2. «Поделиться» → «На экран Домой» → «Добавить».

## 2. Подключить базу данных (один раз, ~5 минут)
1. Зарегистрируйся на https://supabase.com → **New project** (любое имя, придумай пароль базы, регион поближе) → подожди ~1 минуту.
2. Слева **SQL Editor** → вставь всё из файла `supabase.sql` этого репозитория → **Run**.
3. Слева **Authentication → Sign In / Providers → Email**: выключи **Confirm email** → Save (чтобы не ждать письмо). Можно и не выключать — тогда подтвердишь почту по ссылке из письма.
4. Слева **Project Settings → API Keys** (или Data API): скопируй **Project URL** и ключ **anon / publishable**.
5. В приложении: **Настройки → База данных** → вставь URL и ключ → «Подключить базу» → впиши почту и пароль → **Создать аккаунт**.

Готово: внизу заголовка будет написано «сохраняется в облаке». На другом устройстве просто войди тем же email и паролем.

Чтобы не вводить URL и ключ на каждом устройстве, можно вписать их в `config.js`.
